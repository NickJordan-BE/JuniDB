# JuniDB
Dedicated to my cat Juni, this is an ultralearning project on OLAP + realtime data streaming services.
This will be a complete OLAP DB written in Rust with minimal external crate dependencies to learn low-level
details behind distributed OLAP databases such as StarRocks. The features supported will be directly tied to my
RealtimeRecSys project where I will use JuniDB as the storage engine in my distributed realtime recommendation system.

There are three main goals:
- Learn Rust and a little C++
- Deeply understand OLAP distributed databases
- Ruthlessly optimize my deep work, learning, and developer workflows
- Try to be a better engineer

There are also a few rules:
- Not allowed to depend on external crates except for something large like gRPC framework
- Not allowed to use AI at all until I've struggled for more than 30 minutes on a single bug
however this does not mean I will not use AI to learn/study these concepts
- I will treat this as a professional project

/docs contains notes about architecture decisions and implementation workflows
